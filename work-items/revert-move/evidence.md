## SMELT decisions and design-only review

Design resolves root-only feasibility by requiring a future forward writer dependency:
versioned self-contained manifest plus durable final COMPLETE after stage cleanup. Legacy
explicit mode requires every journal row freshly terminal-consistent; no claim to know
historical process exit. Any intermediate/contradictory state is manual-only. This is
AGENT completion semantics, not an invented USER answer. See ADR006 for tradeoffs.

USER directory clarification changes the restoration algorithm: no missing original
subfolders are created; all ordinary archive directories must already match. Extra
original directories are allowed. Validated reserved control tree alone is excluded;
unregistered archive files are not moved. Existing leaf of any kind globally blocks.
