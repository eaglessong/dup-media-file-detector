# Patrol port

Port Cowork /patrol to this repository so an owner can publish grounded PR review
findings using the existing code-review engine. Support selected PRs, bounded-time
open-PR sweeps, dry runs, duplicate-post recovery and honest partial failures.

Acceptance R1–R6 and scope are in docs/design/patrol-port.md. Shared supporting materials
stay in docs/. Do not invoke live patrol or merge this port merely to test installation.
