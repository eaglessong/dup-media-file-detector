# First scan — execution evidence

## PROSPECT and test data

Facts with receipts, assumptions, fixture sources, and unresolved gaps.

## SURVEY and decisions

User answers, AGENT defaults, and links to ADRs.

## Implementation and requirement coverage

Link the design and map each requirement to implementation and behavioral assertions.

## Verification runs

Record exact commands, environment, exit codes, and outcomes. Distinguish application,
integration, E2E, and framework validation. Never mark an unrun command as passing.

## ASSAY findings and dispositions

Label independent review or self-review. Include findings, evidence, fixes/refutations,
and remaining blockers. If no findings, state what was inspected and why.

## Delivery

PR URL, CI results, owner demo instructions, remaining limitations, and resume notes.
